# 🤖 GPT 기반 자동 SKU 매칭 시스템

## 개요

쿠팡 2P 데이터 처리 시 매칭되지 않는 신규 옵션을 GPT가 자동으로 분석하여 SKU_master 테이블에 추가하는 지능형 시스템입니다.

## 🎯 작동 원리

### 1단계: 1차 매칭
기존 방식대로 SKU_master 테이블과 직접 매칭을 시도합니다.

### 2단계: GPT 분석 (매칭 실패 시)
매칭에 실패한 옵션들을 GPT가 다음 3가지 케이스로 분류합니다:

#### 케이스 1: 수량변경 자동생성
- **특징**: 기존 제품과 동일하지만 수량/용량만 변경
- **예시**: "500ml" → "1L", "10개입" → "20개입"
- **ID 생성 규칙**: `기존ID-1`, `기존ID-2`, `기존ID-3`...
- **데이터 처리**: 기존 제품 데이터 복사 후 원가/정가를 수량 비율로 조정

#### 케이스 2: 환불재판매
- **특징**: 환불/반품된 상품을 재판매
- **키워드**: "환불", "반품", "리퍼", "중고", "B급" 등
- **ID 생성 규칙**: `기존ID-A`, `기존ID-B`, `기존ID-C`...
- **데이터 처리**: 기존 제품 데이터 복사 후 원가/정가에 할인 적용 (70-80%)

#### 케이스 3: 신규상품
- **특징**: 완전히 새로운 상품
- **ID 생성 규칙**: 새로운 숫자 ID (현재 최대값 + 1)
- **데이터 처리**: GPT가 상품명, 카테고리 등을 분석하여 새 레코드 생성

### 3단계: SKU_master 자동 생성
GPT 분석 결과에 따라 새로운 SKU_master 레코드를 자동 생성하고 DB에 삽입합니다.

### 4단계: 재매칭 및 저장
새로 생성된 SKU로 매칭을 완료하고 sales_report_coupang_2p 테이블에 저장합니다.

## 📋 설정 방법

### 1. OpenAI API 키 발급
1. https://platform.openai.com/api-keys 방문
2. API 키 생성
3. `.env` 파일에 추가:
```env
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxx
OPENAI_MODEL=gpt-4o-mini
```

### 2. 필수 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 실행
```bash
python main.py
```

## 📊 데이터베이스 변경사항

### SKU_master 테이블
- **변경 없음**: 기존 스키마 유지
- **자동 레코드 추가**: GPT가 분석한 신규 상품 자동 삽입

### 새로운 ID_master 형식
- 기존: `1`, `2`, `3`, ... (숫자만)
- 추가:
  - `42-1`, `42-2` (수량변경)
  - `15-A`, `15-B` (환불재판매)
  - `201`, `202` (신규상품)

## ⚙️ 고급 설정

### GPT 모델 변경
`.env` 파일에서 모델 지정:
```env
# 빠르고 저렴 (권장)
OPENAI_MODEL=gpt-4o-mini

# 더 정확한 분석
OPENAI_MODEL=gpt-4o

# 레거시
OPENAI_MODEL=gpt-3.5-turbo
```

### GPT 없이 사용
- OpenAI API 키가 없으면 자동으로 기존 방식(템플릿 기반)으로 동작
- 매칭 실패 시 unmatched 파일 생성

## 💰 비용

### GPT-4o-mini (권장)
- 입력: $0.150 / 1M tokens
- 출력: $0.600 / 1M tokens
- **예상 비용**: 상품 1개 분석에 약 $0.001 (1000개 처리 시 약 $1)

### GPT-4o
- 입력: $2.50 / 1M tokens
- 출력: $10.00 / 1M tokens
- **예상 비용**: 상품 1개 분석에 약 $0.02 (100개 처리 시 약 $2)

## ❓ FAQ

**Q: GPT 분석이 느린가요?**
A: 상품 1개당 약 1-2초 소요됩니다. 10개 미매칭 상품은 약 10-20초면 처리됩니다.

**Q: GPT가 잘못 분류하면?**
A: 확신도(confidence)가 낮으면 수동 확인을 권장합니다. 생성된 SKU_master를 나중에 수정할 수 있습니다.

**Q: 기존 데이터에 영향이 있나요?**
A: 없습니다. 새로운 SKU만 추가되며 기존 데이터는 변경되지 않습니다.

**Q: 쿠팡 1P는 지원하나요?**
A: 현재는 쿠팡 2P만 지원합니다.

## 🔧 문제 해결

### "OpenAI API key not found"
→ `.env` 파일에 `OPENAI_API_KEY` 추가

### "GPT 시스템 초기화 실패"
→ `pip install openai` 실행 후 재시도

### "Rate limit exceeded"
→ OpenAI API 사용량 초과. 잠시 후 재시도하거나 유료 플랜 업그레이드
